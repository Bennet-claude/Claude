# Fotos

Hier kommen die echten Fotos aus dem Salon hinein.

| Dateiname | Wofür | Format |
|---|---|---|
| `salon-innen.jpg` | Der Salon von innen, auf `salon.html` | Hochformat 4:5, ab 1200 px breit |
| `vorschau.jpg` | Vorschaubild beim Teilen (WhatsApp, Facebook) | 1200 × 630 px |
| frei wählbar | Galerie-Bilder auf `galerie.html` | Hochformat 4:5, ab 1000 px breit |

Vor dem Hochladen: Bilder auf maximal ca. 300 KB verkleinern, sonst lädt die
Seite auf dem Handy langsam. Kundenfotos nur mit Einwilligung der abgebildeten
Person, bei Kindern mit Einwilligung der Eltern.
